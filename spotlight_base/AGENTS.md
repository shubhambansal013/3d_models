# Spotlight Twist-Lock Mount

Single-file OpenSCAD project: `spotlight_base/base.scad`

## View modes

Set `view_mode` to render a specific part (the parameter block is the first section in the file):
- `"assembled"` (default) — both parts mated together, cap seated
- `"base_plate"` — ceiling side (male insert) only
- `"mount_plate"` — light side (female socket) only
- `"lock_tab_linear"` / `"lock_channel_linear"` — individual lock feature debugging
- `"diff_check"` — geometric overlap (intersection) between the two plates

Use `xvfb-run -a openscad base.scad -D 'view_mode="..."' -o out.png --viewall --imgsize=W,H`
for renders (the `openscad_*` MCP render tools are unreliable in this environment).
Pass `view_mode` as a variable.

## Naming

- **Base plate** = ceiling side, male insert (module `base_plate()`, lock tabs `lock_tab()`)
- **Mount plate** = light fixture side, female socket (module `mount_plate()`, lock channels `lock_channel()`)
- Assembly: base plate screws to ceiling → mount plate twists on → spotlight screws onto mount plate.

## Key parameters (top of file)

- Base: `plate_radius` (50), `plate_thickness` (4), `wire_hole_radius` (25), `screw_*` (r=35, 90°/270° counterbored M3)
- Lock: `lock_width` (8), `lock_protrusion` (1.0), `lock_taper`/`lock_height`/`lock_gap_height`, `bend_steps` (24)
- Cap: `cap_radius` (53), `cap_disc_h` (2.5), `cap_skirt_h` (14), `ch_*` (channel groove angles/radii)
- `$fn` = 72 for resolution. Lower for draft renders.

## Design notes

- Twist lock lives on the outer rim, not a central hub. 3-way radial symmetry via `threefold_pattern()` at 0°/120°/240° — one tab per third centered on the fold axis; channels sit 10° behind (`ch_ang_rot = -10`) for a ~10° drop-on twist travel.
- Base plate is a Ø100×4 annulus with a Ø50 central wire hole; screws counterbored flush from the light side. Tabs embed 0.25mm into the rim (`z_off=1.25`); tab tip radius = 50.75.
- Mount plate is a Ø106 cap: 2.5mm disc + 14mm skirt reaching the ceiling, fully hiding the base. Central Ø9.5 boss with Ø2.9 self-tap pilot holds the spotlight; Ø8 wire-exit hole at r=12. Hollow interior (r up to 51) carries wire slack.
- `rim_channel()` builds each groove directly from annular sectors (outer wall ring + roof overhang + back-wall slab) — no difference-based void, so the back-wall stop face survives.
- `mount_offset_z = (2 + plate_thickness) − (cap_disc_h + cap_skirt_h)` seats the cap so its skirt top meets the base's ceiling face.
- `cylindric_bend()` transforms flat lip geometry into curved tabs along a cylinder radius (`bend_r = plate_radius + 1.0`).
- Lock geometry generated by `lip_prism()` hull sequences — taper, gap, and engagement width.
- Known cosmetic artifact: `cylindric_bend` slice boundaries create coincident faces → CGAL reports non-manifold edges / extra volumes. Renders "Simple: yes", one connected part; accepted as-is.
