# Spotlight Twist-Lock Mount

Single-file OpenSCAD project: `spotlight_base/base.scad`

## View modes

Set `view_mode` at line 8 to render a specific part:
- `"assembled"` (default) — both parts mated together
- `"receptacle"` — female socket only
- `"plug"` — male insert only
- `"pluglip_linear"` / `"reclip_linear"` — individual lock tab debugging
- `"diff_check"` — geometric overlap (intersection) between plug and receptacle

Use `openscad_*` MCP tools to render, analyze, or export. Pass `view_mode` as a variable.

## Naming

- **Plug** = base plate (ceiling side, male insert)
- **Receptacle** = mount (light fixture side, female socket)

## Key parameters (top of file)

`plug_radius` (8), `tolerance` (0.2), `mating_dist` (5.0), `lip_*`, `flange_radius` (10), `bend_steps` (20).
`$fn` = 72 for resolution. Lower for draft renders.

## Design notes

- 3-way radial symmetry via `tri_pattern()` at 0°, 120°, 240° — tabs land at 60°, 180°, 300°.
- Plug shaft uses `cylinder_arc_sections()` to produce 3×60° arcs (only tab-supporting sections remain).
- Receptacle uses a full continuous outer cylinder below the flange ring.
- `cylindric_bend()` transforms flat lip geometry into curved tabs along a cylinder radius.
- Lock geometry generated by `liprism()` hull sequences — taper, gap, and engagement width.
